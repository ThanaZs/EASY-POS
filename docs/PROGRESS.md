- actions ใหม่: `bulkPinAction`, `bulkTrashAction` (audit ทีละสินค้า); หมวดที่เลือกไม่มีแล้ว → redirect ไปทุกหมวด
- ตรวจแล้ว: tsc, lint, build; localhost 375px ผู้ใช้ทดสอบ (ลบแล้ว): ปัด→ปักหมุด ขึ้นบนสุดพร้อมหมุดเอียง, เลือกทั้งหมดในหมวด→ลบ 3 รายการ→แจ้ง+ลิงก์ถังขยะ, หน้าประวัติแสดงถูก แตะแถวเปิดสินค้าได้
